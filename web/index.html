Rest Easy

Your screen gets drunk the longer you keep your eyes open.
The only fix is to close them.

Rest Easy runs on a computer. It needs a webcam, a keyboard and a full screen to wreck, so open it on a laptop or desktop.

Where should the drunk screen happen?

Run the desktop app on Windows or a Mac with Node 24: Linux starts, but its screen capture isn't tested yet.

git clone https://github.com/matias-io/sih-rest-easy
cd sih-rest-easy
npm install
npm run desktop
Fully open source. Read the code, or have your own AI agent audit it before you run it.

No camera? Hold Space to close your eyes. Esc ends it.
